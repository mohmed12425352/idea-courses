# منظومة التطبيقات المستقلة — Idea Courses Apps (الديسكتوب + الموبايل + داتا بيز سحابية منفصلة)

هذا المجلد (`D:\data\edunova-apps-platform`) هو **نظام مستقل بالكامل 100%** عن نسخة الموقع (`D:\data\edunova-academy-fullstack`)، ومخصّص حصرياً لتشغيل وإدارة **تطبيق الويندوز (`.exe`) وتطبيق الموبايل (`Android .apk` + `iOS`)** بقاعدة بيانات ولوحة تحكم خاصة بهم فقط!

---

## 1. هيكلة المشروع المستقل

| المجلد | الوظيفة |
|--------|---------|
| **`backend/`** | باك إند مستقل تماماً يعمل على المنفذ `4500` بقاعدة بيانات معزولة (`backend/data/apps-pgdata`) ويدعم التحويل الفوري لـ **Cloud PostgreSQL** (Neon / Supabase / Railway) مع بث حي لحظي (`WebSockets /ws`). |
| **`app-ui/`** | واجهة التطبيقات ولوحة تحكم الأدمن المستقلة (`/admin`) بتصميم مخصّص للموبايل (شريط تنقل سفلي + Safe Area) والديسكتوب. |
| **`desktop/`** | تطبيق الويندوز المحمي (`Idea Courses - Eng Ehab El-Galaly.exe`) المربوط بسيرفر التطبيقات المستقل (`4500` أو السحابي). |
| **`mobile/`** | مشروع الموبايل الرسمي (**Android `.apk` + iOS Xcode**) المبني بـ **Capacitor 7** مع حماية أصلية على مستوى نظام الأندرويد (`WindowManager.LayoutParams.FLAG_SECURE`) و الـ iOS (`UIScreen.isCaptured`) وبصمة هاردوير الموبايل (`ANDROID_ID`). |

## 3. إزاي تخلي الداتا بيز والتطبيقات "تسمّع عند الناس" في أي مكان بدون فتح جهازك؟

تم تجهيز طريقتين سهلتين جداً:

### الخطوة (أ): ربط قاعدة بيانات سحابية مجانية في 30 ثانية (Neon.tech أو Supabase)
1. افتح موقع **https://neon.tech** (أو **Supabase**) وأنشئ مشروع PostgreSQL مجاني وانسخ رابط الاتصال (`postgresql://...`).
2. افتح لوحة تحكم التطبيقات `http://localhost:4500/admin` -> ادخل على تبويب **الأجهزة** -> ستجد بطاقة **"☁️ قاعدة البيانات السحابية المستقلة"**.
3. الصق الرابط واضغط **"ربط الداتا بيز السحابية فوراً"** — سيقوم السيرفر تلقائياً بإنشاء الـ 33 جدول والـ Triggers وحساب الأدمن على السحابة وحفظ الإعدادات بدون حتى إعادة تشغيل!

### الخطوة (ب): رفع سيرفر التطبيقات أونلاين مجاناً 24/7 (Railway أو Render)
يوجد في هذا المجلد ملفات جاهزة للنشر بضغطة واحدة:
- [`Dockerfile`](./Dockerfile)
- [`railway.json`](./railway.json)
- [`render.yaml`](./render.yaml)

بمجرد رفعه على **Railway** أو **Render** ستحصل على رابط سحابي دائم (مثل `https://idea-courses-apps.up.railway.app`)؛ ضعه في `desktop/config.json` أو من زر **`⚙ السيرفر`** أعلى تطبيق الديسكتوب وتطبيق الموبايل ليسمّع كل تعديل أو كورس أو إشعار لحظياً عند كل الطلاب في أي مكان!
